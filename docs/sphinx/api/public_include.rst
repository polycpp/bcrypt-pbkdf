``polycpp/bcrypt_pbkdf.hpp``
============================

Use this umbrella header for the public API:

.. code-block:: cpp

   #include <polycpp/bcrypt_pbkdf.hpp>

It includes the KDF functions, constants, and typed error surface. Headers
under ``polycpp/bcrypt_pbkdf/detail/`` are internal and are not part of the
supported API.

Public declarations are documented on
:doc:`polycpp/bcrypt_pbkdf/bcrypt_pbkdf.hpp <bcrypt_pbkdf>` and
:doc:`polycpp/bcrypt_pbkdf/error.hpp <error>`.
